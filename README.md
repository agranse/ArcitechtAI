# Architect AI
**AI‑powered codebase architecture analysis — free, local, and developer‑friendly.**

Architect AI blends static analysis, graph theory, and local LLM reasoning to
produce deep architectural insights for any codebase. It generates dependency
graphs, complexity heatmaps, architecture diagrams, technical‑debt reports, and
AI‑driven refactor plans — all without paid APIs.

---

## ✨ Features

- **Static Analysis Engine**
  - Dependency graph generation  
  - Circular dependency detection  
  - Complexity scoring  
  - Code smell detection  

- **AI Reasoning Layer (Local LLMs)**
  - Architecture summaries  
  - Risk analysis  
  - Refactor suggestions  
  - Mermaid architecture diagrams  

- **Interactive Visualizations**
  - D3/Cytoscape dependency graph  
  - Complexity heatmap  
  - Module explorer  
  - Mermaid diagrams  

- **VS Code Extension**
  - “Analyze Project” command  
  - Side panel insights  
  - Hover diagnostics  
  - Refactor suggestions  

- **CLI Tool**
  - Run full analysis  
  - Export reports  
  - CI/CD integration
